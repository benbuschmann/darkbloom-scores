How to find your SE public key

On each Mac running Darkbloom, open Terminal and run:

python3 -c 'import json,pathlib; print(json.loads((pathlib.Path.home()/".darkbloom/daemon-state.json").read_text()).get("attestation_public_key") or "No public key available")'

Copy the public key into the public directory search box. No login or API key is needed. The key follows reconnects; a replacement key starts a separate identity.

Coverage and estimated base reward

Base is an “up to” public eligibility scenario, separate from job charts. Public App Attest authorization, macOS 27+, online status and a current model are required. The official uptime ramp is zero at 90%, rising to full at 100%; we approximate it from minute samples. Private health, OS-bound authorization, account/machine binding, pool allocation and reduction settings are unknown. Missing minutes count against eligibility.
